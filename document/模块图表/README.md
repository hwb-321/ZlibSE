# 后端模块图表

本目录按后端模块拆分存放 Mermaid 图表，默认说明口径按功能全部开启：

- Redis 开启
- 一级缓存开启
- 验证码开启
- 搜索限流开启
- 下载热点缓存开启
- 调试指标开启
- 异步解析开启，模式为 `on`
