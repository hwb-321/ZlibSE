# 后端接口说明

## 说明

本文档覆盖当前后端实际提供的全部主要接口。

接口分为以下几类：
- 认证接口
- 文件接口
- 书籍接口
- 收藏接口
- 上传记录接口
- 调试接口

当前后端已经移除旧的文件直传和旧的书籍下载接口。

不再使用的旧接口：
- `POST /book/upload_book`
- `GET /book/download/{book_id}`
- `GET /book/download/{book_id}.epub`
- `POST /user/change_uploaded_book/{book_id}`
- `GET /user/init_csrf`
- `GET /user/check_session`
- `POST /user/logout_user`

当前推荐的新流程是：
- 先通过文件接口上传正文和封面
- 得到 `fileId`
- 再通过书籍接口创建或编辑书籍
- 下载时通过文件接口按 `fileId` 获取下载地址

## 推荐顺序

### 创建书籍

1. 前端获取验证码并完成登录
2. 前端上传正文文件：`POST /api/files/upload-url`
3. 前端把正文直传 COS
4. 前端通知后端落库：`POST /api/files/upload-complete`
5. 得到正文 `bookFileId`
6. 如果有封面，重复以上流程得到 `coverFileId`
7. 前端提交书籍信息：`POST /api/books`

### 编辑书籍

1. 如果正文或封面需要替换，先重新走文件上传流程
2. 得到新的 `bookFileId` 或 `coverFileId`
3. 前端调用：`PUT /api/books/{book_id}`

### 下载文件

1. 前端先拿到书籍详情中的 `book_file_id` 或 `cover_file_id`
2. 请求：`GET /api/files/{file_id}/download-url`
3. 后端返回预签名下载链接
4. 前端使用返回的 `downloadUrl` 进行下载

### 预览封面

如果需要直接预览封面，可以使用：
- `GET /api/files/{file_id}/content?download=false`

## 认证接口

### 认证方式

后端已切换为 JWT 认证。

需要登录的接口统一通过以下请求头鉴权：

```http
Authorization: Bearer <access_token>
```

当前后端不再使用 Session、CSRF 初始化接口和登录失败次数限制。

权限原则：
- 公开读：书籍列表、搜索、详情、下载接口无需登录
- 登录写：上传、改书、删书、改密码等写操作需要登录
- 普通用户只能修改或删除自己上传的书籍
- 管理员可以修改或删除任意书籍

### 1. 生成验证码

`GET /user/generate_captcha`

返回体示例：

```json
{
  "key": "captcha-key",
  "image_url": "/user/captcha/image/captcha-key"
}
```

### 2. 获取验证码图片

`GET /user/captcha/image/{captcha_key}`

说明：
- 返回 PNG 图片流
- 验证码过期时返回 404

### 3. 注册

`POST /user/register_user`

表单字段：
- `username`
- `email`
- `password`
- `captcha_key`
- `captcha_value`

返回体示例：

```json
{
  "success": true,
  "message": "注册成功"
}
```

### 4. 登录

`POST /user/login_user`

表单字段：
- `username`
- `password`
- `captcha_key`
- `captcha_value`

返回体示例：

```json
{
  "success": true,
  "access_token": "jwt-token",
  "token_type": "bearer"
}
```

说明：
- 登录成功后返回 JWT access token
- token 内包含用户 id、token 版本和过期时间
- 前端负责保存和删除 token

### 5. 检查登录状态

`GET /user/check_auth`

请求头：
- `Authorization: Bearer <access_token>`

成功返回体示例：

```json
{
  "isLoggedIn": true,
  "captchaEnabled": false,
  "user": {
    "id": 1,
    "username": "xxx",
    "is_superuser": false
  }
}
```

说明：
- token 无效、过期或版本不匹配时返回 `401`

### 6. 修改密码

`POST /user/change_password_user`

请求头：
- `Authorization: Bearer <access_token>`

表单字段：
- `current_password`
- `new_password`

返回体示例：

```json
{
  "success": true,
  "message": "密码已更新"
}
```

说明：
- 修改密码成功后，后端会将用户的 `token_version` 加一
- 该用户此前签发的所有旧 token 会立即失效

## 文件接口

### 1. 获取上传地址

`POST /api/files/upload-url`

请求体：

```json
{
  "filename": "example.epub",
  "contentType": "application/epub+zip",
  "size": 123456,
  "kind": "book"
}
```

说明：
- `kind` 只能是 `book` 或 `cover`
- 该接口只负责签发预签名上传地址
- 需要登录

返回体示例：

```json
{
  "objectKey": "books/2026/03/uuid.epub",
  "uploadUrl": "https://...",
  "expiresIn": 900,
  "headers": {
    "Content-Type": "application/epub+zip"
  }
}
```

### 2. 上传完成回调

`POST /api/files/upload-complete`

请求体：

```json
{
  "objectKey": "books/2026/03/uuid.epub",
  "originalFilename": "example.epub",
  "contentType": "application/epub+zip",
  "size": 123456,
  "kind": "book",
  "etag": "optional-etag"
}
```

返回体示例：

```json
{
  "fileId": 12
}
```

说明：
- 该接口会检查对象是否已经存在于 COS
- 该接口只负责写入 `stored_files`
- 需要登录

### 3. 获取下载地址

`GET /api/files/{file_id}/download-url`

说明：
- 该接口为公开分享接口，无需登录

返回体示例：

```json
{
  "downloadUrl": "https://...",
  "expiresIn": 300,
  "filename": "example.epub"
}
```

### 4. 后端代理读取文件

`GET /api/files/{file_id}/content`

查询参数：
- `download=true|false`

说明：
- `download=true` 时，按附件下载
- `download=false` 时，更适合图片预览这类场景
- 对旧本地文件和 COS 文件都兼容
- 该接口为公开分享接口，无需登录

## 书籍接口

### 1. 创建书籍

`POST /api/books`

请求体：

```json
{
  "title": "示例书籍",
  "author": "作者",
  "isbn": "1234567890",
  "category": "技术",
  "year": 2026,
  "language": "zh-CN",
  "bookFileId": 12,
  "coverFileId": 13
}
```

说明：
- `bookFileId` 必填，并且必须指向 `kind=book` 的文件记录
- `coverFileId` 选填，如果提供，必须指向 `kind=cover` 的文件记录
- 需要登录

返回体示例：

```json
{
  "success": true,
  "book": {
    "id": 1,
    "title": "示例书籍"
  }
}
```

### 2. 编辑书籍

`PUT /api/books/{book_id}`

请求体和创建书籍一致。

说明：
- 普通用户只能修改自己上传的书籍
- 超级用户可以修改全部书籍
- 需要登录

### 3. 书籍列表

`GET /book/list?page=1&pageSize=10`

说明：
- 该接口为公开分享接口，无需登录

返回体示例：

```json
{
  "books": []
}
```

### 4. 书籍详情

`GET /book/get_descriptions/{book_id}`

返回字段中会包含：
- `book_file_id`
- `cover_file_id`
- `file_path`
- `cover_image_path`

说明：
- `file_path` 现在返回的是文件下载接口地址，不再是旧的本地文件路径
- `cover_image_path` 现在返回的是文件内容接口地址，不再是旧的本地图片路径
- 该接口为公开分享接口，无需登录

### 5. 搜索书籍

`GET /book/search?query=关键词`

说明：
- 该接口为公开分享接口，无需登录

### 6. 统计书籍数量

`GET /book/count`

说明：
- 该接口为公开分享接口，无需登录

返回体示例：

```json
{
  "count": 10
}
```

## 上传记录接口

### 1. 获取我上传的书籍

`GET /user/get_upload_book_list`

返回体示例：

```json
{
  "uploadedBooks": []
}
```

### 2. 删除已上传书籍

`POST /user/delete_uploaded_book/{book_id}`

说明：
- 删除书籍时，会同时删除：
  - `books` 记录
  - 关联的 `stored_files` 记录
  - COS 中对应的对象
  - 收藏关系和上传关系

返回体示例：

```json
{
  "success": true,
  "message": "书籍及相关文件已删除"
}
```

## 兼容说明

当前后端仍兼容旧数据表中的本地文件历史记录：
- 启动时会把旧 `books.file_path`、`books.cover_image_path` 尽量回填到 `stored_files`
- 旧的本地文件记录会以 `legacy-local` 的形式保留
- 新上传文件统一写入 COS
